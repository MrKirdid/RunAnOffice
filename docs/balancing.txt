====================================================================================================
1. FORMULAS
====================================================================================================
  Income per second (paid every 1s, floored to a whole dollar):
      sum over every STAFFED desk of  (Keyboard 1 + Monitor 1.5 + Computer 3, each x its part's variant
      value)  x  employee multiplier
      x  tree cash multiplier (1 + bought Cash nodes, additive)
      x  shop cash multiplier (ladder rung x 1.25 if VIP)
      x  friends (1 + 0.1 per friend in the server, max 5 friends = 1.5x)
  A full set of one variant on a desk = 5.5 x variant value. An empty seat earns 0.

  Hire cost  = employee multiplier^3 x 100 (rounded).  Sell value = 50% of hire cost (floored).
  Offline    = 100% of the solo rate (no friends boost), capped at 3 days away.
  Skip packs = current rate INCLUDING friends boost x hours.

  Luck: each entry's weight is multiplied by Luck^s, where s runs from 0 (commonest) to 1 (rarest) on a
  log scale. So Luck 2 doubles the rarest chance and barely touches the common ones.
  Player luck = tree luck (starts at 1) x 2 with Lucky Roller x server luck (bought, whole server).
  Part rolls use player luck. Walker employees use 1 x server luck only (see section 12).

12. THINGS THAT LOOK OFF  (found while building this sheet; nothing here was changed)
====================================================================================================
  1. +1 Roll Pad product is broken. It caps at Store.MaxPads = 9 but every save starts with 9 pads,
     so it grants nothing. A player on 11+ pads from the tree would be pushed back down to 9.
  2. The tree says luck improves hires, but walkers roll at luck 1 x server luck. Player luck and
     Lucky Roller never touch employees. Either the text or the code is wrong.
  3. Defense branch (Base Locker / Stronger Defenses / Super Lasers, 1,365,000 total) does nothing yet.
  4. Pack income dwarfs the early game: Starter (R$49) adds ~4,125/s at a stage where a desk
     earns 22-100/s, skipping most of floor 1-2 pacing. Might be intended, but worth a look.
  5. Desk 1 comes built in the save, so the first desk anyone buys costs 450. The 250 price is never
     charged, yet the save's starting cash comment says 1,000 is 'enough for the first desk at 250'.
  6. A comment in UpgradeDefinitions says Cash IV reads 3.75x; the four Cash nodes actually total 4.75x.
